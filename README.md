# Student Performance Analysis

A Python-based data analysis project using Pandas, NumPy, and Matplotlib to analyze student performance.

## Project Overview

This project analyzes student academic performance based on:

- Math scores
- Science scores
- Attendance
- Department
- Age

The project also handles missing values, calculates total and average scores, assigns grades, and performs department-wise analysis.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- GitHub

## Key Analysis

### 1. Missing Value Handling

Missing values were identified and replaced using appropriate values such as column averages.

### 2. Student Performance

Calculated:

- Total Score
- Average Score
- Grade

### 3. Department-wise Analysis

Compared CSE and ECE departments based on:

- Average Score
- Math Score
- Science Score
- Attendance

### 4. Correlation Analysis

Analyzed the relationship between:

- Math
- Science
- Attendance
- Average Score
